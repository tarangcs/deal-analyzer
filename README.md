# CBTE Deal Analyzer

Shared web app for the Charlotte Based Transaction Engineers to evaluate
wholesale/flip real estate deals.
See `CLAUDE.md` for stack, working agreement, and the calculation
fixture; see `.claude/plans/i-want-to-build-swirling-barto.md` for the
full build roadmap.

## Development

```bash
npm install
npm run dev       # start dev server
npm run build     # type-check + production build
npm run lint       # oxlint
```
